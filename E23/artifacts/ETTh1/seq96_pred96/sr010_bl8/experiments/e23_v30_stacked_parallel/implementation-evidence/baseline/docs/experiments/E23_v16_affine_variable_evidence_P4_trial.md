# E23 v16: train-observed affine alignment of V evidence

Predeclared 2026-10-01. E23 v12 remains the incumbent (validation MSE/MAE `0.7454477286392869` / `0.5882120694703256`; selected test `0.4256128043003904` / `0.431006140719736`). The v12 read-only diagnostic found that raw source values are poor proxies for hidden target values and that a source-to-target affine fit using jointly observed training positions lowers MAE beyond a zero baseline for six of seven variables. It also found that swapping only the v12 V source set at inference has negligible aggregate forecast effect. This trial therefore changes the **V evidence values and their consistency check**, not merely the top-four ranking weight.

Fit one directed affine map per source-target pair on the normalized historical windows from a fixed, deterministic train epoch, using only coordinates where both variables are originally observed. Freeze these maps as checkpointed buffers for both stages and inference. In V, transform every available source value before the existing aligned-patch consistency calculation, candidate scoring, and candidate message projection; missing source positions remain exactly zero and cannot contribute values. The top-four cap, context score coefficients, offsets, V message network size, H/T experts, shared router, explicit repair, and original width-16 PatchTST predictor remain as in v12. No future targets, validation labels, test labels, or generated repair values enter the map fit or V source features.

Use the locked ETTh1 P4 split, fixed masks and training schedule: seed 2021, repair width 64, batch 128, 100 Stage-1 epochs and 100 Stage-2 epochs. Select Stage 1 by earliest minimum validation hidden repair MSE. Stage 2 uses `MSE + 0.2 MAE` and selects the earliest minimum validation forecast MAE. Promote v16 only if validation MAE is **strictly lower** than `0.5882120694703256` and validation MSE is **no higher** than `0.7454477286392869`. Check the checkpoint/manifest identity, frozen H state, complete epochs, and exact validation replay before any selected test. If the gate fails, keep v12 and do not evaluate v16 on test.

This is one proposed method change and one seed. A favorable result would remain exploratory because the same ETTh1 validation protocol has informed prior E23 development. The trial does not establish that a new forecast head is necessary; later multi-head experiments will evaluate whether the recovery encoder can be reused or jointly adapted with other predictors.

## Result

The two fresh stages each completed all 100 epochs. Stage 1 selected epoch 91 at hidden-coordinate validation repair MSE `106.85290526175122`, a small improvement over v12's `106.9069637043`. Stage 2 selected epoch 57 at validation forecast MSE `0.7601933911814441`, MAE `0.5913984380882072`. Both forecast metrics are worse than v12 by `0.0147456625` MSE and `0.0031863686` MAE. **V16 fails the predeclared promotion gate; v12 remains the selected E23 model.** No v16 test evaluation was run.

The selected Stage-2 checkpoint was reloaded from its paired manifest and replayed over all 2,688 fixed-validation windows (1,806,336 future coordinates), reproducing the selected MSE and MAE exactly. The H retrieval key checksum was `c5873a1c88b5a35732e959274166031dc443d3888371b877440a072f62ffa6bd` before and after replay. The affine maps are checkpointed V buffers. The controlled observation here is that lower hidden-coordinate repair MSE did not translate into better future forecasting; it does not prove that all cross-variable alignment is harmful.
