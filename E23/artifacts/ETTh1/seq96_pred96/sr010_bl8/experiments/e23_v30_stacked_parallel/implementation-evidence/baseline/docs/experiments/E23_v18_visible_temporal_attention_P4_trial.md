# E23 v18: visibility-aware multihead temporal expert

Predeclared 2026-10-01, before training. The selected ETTh1 P4 incumbent is v12: validation forecast MSE/MAE `0.7454477286392869` / `0.5882120694703256`; selected test `0.4256128043003904` / `0.431006140719736`. A read-only v12 validation ablation found that masking T raised MSE/MAE by `0.02020167980064347` / `0.010403177905785488`, the smallest marginal effect among H/V/T. T still helps. This trial tests whether a stronger within-window T representation adds complementary forecast information.

Change only the T expert. Retain v12's H and V architectures and selection rules, shared router, explicit repair, width-64 repair latent, original width-16 PatchTST prediction head, masks, losses, and training schedule. Replace T's one-source-per-directional-band reduction with four-head query-to-source attention over all other patches of the **same variable in the current 96-point lookback** that contain at least one originally observed value. Source values at hidden positions are zero and the observation mask enters the source encoder. A source's attention logit combines learned query-key similarity with fixed `+0.5 × observed source fraction`, `+0.25 × exp(−observed-overlap MAE)` (zero when no overlap), `−0.05 × normalized temporal distance`, and a learned direction/distance-band bias per head. The four attended source-value heads are concatenated and projected; target base latent and weighted observed-evidence summaries form T's message and quality. Invalid and self sources receive zero weight. No repaired values, future targets, validation labels, or test labels enter T's evidence.

Train both stages from fresh seed 2021 for 100 epochs each on the locked ETTh1 P4 96→96 split, batch 128. Stage 1 selects earliest minimum fixed-validation hidden-coordinate repair MSE. Stage 2 uses `MSE + 0.2 MAE` and selects earliest minimum fixed-validation forecast MAE. Replay the selected Stage-2 checkpoint and verify the H memory/key state. Promote v18 only if validation forecast MAE is strictly below `0.5882120694703256` **and** validation MSE is no higher than `0.7454477286392869`. If either fails, retain v12 and do not evaluate v18 on test. One seed on repeatedly used ETTh1 validation is exploratory even if the gate passes.
