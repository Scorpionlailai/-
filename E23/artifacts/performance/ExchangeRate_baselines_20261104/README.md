修复表按原Stage1规则选模；预测主表按验证MAE选择，验证MSE选择作为单独次选表完整保留，不能按测试择优。

## 口径与资产边界

- sr010_bl8、sr015_bl8、sr020_bl8、sr010_bl16分别为起点率/块长0.10/8、0.15/8、0.20/8、0.10/16；起点率不是最终点缺失率。
- 时间划分边界0/5311/6070/7588；测试每mask1423个窗口。指标在训练集标准化尺度，缺失修复仅计人工隐藏坐标，预测计未来目标。
- 预测Stage2为冻结修复器＋共享预测头，100轮、4000更新，纯forecast MSE训练；同时保存验证MAE和MSE选模结果。它与11月Beijing阶段二精恢复不是同一实验。
- BRITS使用已确认TorchScript循环加速、最多200轮、patience20。CSDI使用最终执行记录：sr010_bl8/sr015_bl8复用200轮Stage1，sr020_bl8/sr010_bl16为100轮Stage1，仍50步扩散；预测训练1个样本、修复及预测评价5个样本，采样聚合沿用记录。不能把四场景误记为同一Stage1轮数或旧10样本方案。
- 耗时和显存来自原training_resources及逐阶段资源文件，保留batch/精度/硬件一致性字段；各模型batch和精度不同，hardware_consistent=False不被篡改为True。记录为各进程/阶段实际统计，不冒充同batch或同精度的统一效率排名。
- 旧v125 comparison混合模型表不作为当前R3成绩；本档只发六个基线，R3三seed结果已另行归档。
