# E23 v31：Stage2 修复保留与位置收益加权

状态：2026-10-03 完成。按固定验证集选择 **E23 v31 B**；三组测试只评估缺失位置变化，不参与选模或调整后续条件。

## 实验条件

修复器沿用 v29-r1 单轮三专家，宽度64，原PatchTST预测器宽度16。修复参数135321、预测器参数35427，无新增推理参数。共同Stage1从头训练100轮，A/B/C各自Stage2训练100轮；seed2021、batch128、FP32、学习率Stage1=0.001、Stage2=0.0001，weight_decay=0。

A/B/C共用本轮Stage1，预测器初始参数SHA完全一致；每个Stage2重置训练RNG、使用独立新优化器。Stage1维持global_mse_v1+0.1检索损失、specialist exposure0.2，最佳第100轮；验证修复MSE=0.290159343、MAE=0.364428077。

| 条件 | Stage2目标 |
|---|---|
| A | 预测MSE+0.2 MAE |
| B | 前10轮同A；第11轮起加0.05均匀全局缺失坐标修复MSE |
| C | 前10轮同A；第11轮起加0.05位置收益加权全局缺失坐标修复MSE |

C每轮开始复制上一轮末整模型，eval且无梯度，整轮不更新教师。每个打乱batch前16窗口进行六个16点时间区间×7变量的42区域真值替换，只替换真实缺失位置及重叠patch副本；可见值、mask、窗口归一化统计和padding保持原值。预测MSE下降定义为正收益，负收益保留作诊断。正收益映射位置后raw权重1–4，再按每窗口缺失坐标均值归一化到1；其他窗口权重1。权重停止梯度。

修复损失在训练集全局标准化尺度、原96点序列缺失坐标上计算，避免重复计入patch覆盖。训练真值用于监督；验证/测试没有教师干预，推理结构完全相同。

## 验证选模与修复诊断

每条件按原固定验证MAE取最优权重，均为第85轮。晋级门槛为验证MSE<0.7499365438950035且MAE≤0.5840456761470457。B/C均通过，B验证MAE更低，按预先固定规则晋级B；测试结果未参与决策。

以下修复MSE/MAE只在原验证集真实缺失坐标上计算，尺度为训练集全局标准化；预测指标覆盖所有未来坐标。

| A | 85 | 0.749936544 | 0.584045676 | 0.536136447 | 0.502366204 |

| C | 85 | 0.746017208 | 0.581938029 | 0.421585255 | 0.446679337 |

B比A同时改善修复与预测。C比B的整体修复MSE略低，预测MSE/MAE却略高；本轮尚未证明位置收益加权能带来额外预测收益。B和C差距很小，不能据一次训练和三个位置draw宣称统计显著。

## 训练资源与覆盖

共同Stage1实测218.803809秒。A/B/C Stage2全流程分别184.041023、184.028215、309.619055秒；每个模型完整成本=共同Stage1+自己的Stage2。实际矩阵共同Stage1只执行一次，合计896.492102秒（14.94分钟）。

C教师复制、区域干预前向及配对修复诊断共124.486213秒，包含在309.619055秒中。C完整模型成本比B增加125.590840秒（31.18%），推理参数和结构没有增加。

第11–100轮5940个batch，C累计评分95040次训练窗口呈现，占约束启用期间760320次呈现的12.5%，占100轮全部844800次呈现的11.25%；这些不是95040个互不相同窗口。其余窗口仍用均匀修复损失。42区域的训练平均有符号收益中15为正、27为负；这里是跨训练阶段教师的累计诊断，不能解释为固定最佳checkpoint的区域收益。数据见区域CSV。

全流程时间包括入口导入、数据准备、模型和优化器构建、全部训练轮次、训练内验证与选模保存；资源侧写文件写入、额外验证重放、修复诊断和测试另计。A/B/C额外三组测试分别2.668279、2.657330、2.662967秒；修复诊断约1.12秒/条件。训练峰值为进程内PyTorch allocator allocated/reserved，不能等同整张显卡占用。

训练设备RTX5090 GPU1，UUID1315e15c-d657-e61f-bde5-6e0b38e6e54b；矩阵开始时没有其他GPU计算进程，条件顺序A→B→C，每条件锁定重放与诊断后立刻测试三组，再启动下一条件。

T1和旧v29-r1使用既有保存结果，本轮没有重跑。T1 Stage1 batch16、BF16、完成74轮，Stage2 batch128、FP32、100轮；E23为两阶段batch128、FP32、各100轮，原论文模型配置差异保留。因此时间/显存是各自实际配置的测量，不代表同精度和同训练预算。
