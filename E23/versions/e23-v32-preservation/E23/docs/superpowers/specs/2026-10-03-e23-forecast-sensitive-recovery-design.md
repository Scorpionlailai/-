# E23 v31：预测收益加权的修复保留

## 目的与范围

用户已确认沿位置级预测收益继续。目标是检验：在单轮H/V/T结构中，将修复监督分配到预计能改善未来预测的位置，是否比均匀修复监督更有效。保持现有宽度64修复模块、宽度16 PatchTST预测器、显式接口及H/V/T策略。首先只改变Stage2训练目标，不新增推理模块或专家数量。训练权重由训练集干预收益产生；可部署的收益评分器与按收益分配额外轮次留待本实验验证后独立设计。

原始证据见 `docs/experiments/2026-10-03_forecast_sensitive_recovery_diagnosis.md`。诊断中LUFL近期位置值得关注，但本实验不硬编码LUFL或近期偏好，所有变量和区域使用同一规则。验证诊断不产生训练权重，测试集不参与设计、收益标注或选模。

## 三个条件

A：原Stage2预测MSE+0.2 MAE。
B：A+0.05×均匀全局缺失位置修复MSE。
C：A+0.05×预测收益加权的全局缺失位置修复MSE。

三个条件使用同一个本轮从头训练100轮的Stage1选定权重；每个Stage2从相同初始修复权重、相同预测器初始化、相同训练seed和mask序列分别运行100轮。Stage2每次重置随机状态并重新构建模型，不继承上一条件的optimizer。三个条件的前10轮均只用A，避免未训练预测器主导监督；B/C从第11轮开始加入修复项。故B是warmup后均匀约束，不能表述成全程均匀约束。

使用本轮新Stage1，避免把旧权重产生的训练成本隐藏掉。完整流程成本分别报告共同Stage1时间+各自Stage2时间；实际整个矩阵只执行一次Stage1，另报告共享Stage1成本及矩阵总成本。旧v29-r1/T1作保存结果参考，不重跑。

## 固定收益教师与标注

C每个epoch开始使用前一个epoch结束的整模型快照，冻结参数、eval模式；不使用验证选定快照、不看验证标签。第11轮教师来自第10轮末。教师包含修复器与预测器，使用同一只读H key/库。整epoch内保持不变，epoch结束再替换。训练模型继续正常train模式。

将原96点时间轴划为六个不重叠16点区域，与七变量组合成42区域。同一原坐标的重叠patch副本全部一致替换；不修改原mask、query mean/std、padding validity或可见值。

每个训练batch，对该batch前16个已打乱窗口计算教师原预测，以及42次各区域缺失值恢复为历史真值后的预测。收益标签：

`Delta[b,g] = mean((base_forecast - future)^2) - mean((region_restored_forecast - future)^2)`。

保留负值用于诊断，训练加权取正部分。教师不回传梯度；训练历史真值只进入上述替换和修复损失，训练未来标签只进入收益计算和预测损失。未受损区域收益强制为0；替换恒等时预测必须一致。没有缺失的窗口权重为1、修复损失为0。

这不是纯预测敏感度：收益同时依赖当前修复误差及固定教师响应。额外记录区域修复误差，便于检查权重是否仅反映困难程度。

## 权重及损失

对有缺失窗口，将42区域正收益映射回原时间坐标。以该窗口缺失坐标上的平均正收益s进行尺度归一化：

`raw_w = 1 + clamp(positive_gain / max(s, 1e-6), 0, 3)`。

再除以该窗口缺失坐标的raw_w均值，使最终缺失权重均值严格为1。raw_w范围1–4，归一化后仍保持正下限，不删除负收益位置的基础监督。不使用top-k、固定近期窗口或固定变量名单。

C在前16个窗口使用上述权重，余下窗口权重1；B全部权重1。两者均在全部batch缺失坐标上计算加权全局修复MSE：

`L_repair = sum(hidden * stopgrad(w) * ((repaired_norm - clean_norm) * query_std)^2) / sum(hidden)`。

权重在序列尺度计算，不能按重叠patch直接累加。query_std来自原可见历史并detach；不再以窗口归一化尺度评分。全batch缺失权重平均为1，两个条件修复系数相同。前16窗口是计算预算限制，记录每batch实际覆盖率；它们来自同一已有打乱顺序，不按标签挑选。

B/C的修复梯度到修复器/decoder，不经预测器；A的预测梯度继续到全部原可训练组件。C收益教师没有optimizer或推理依赖，所有教师运行和复制计入Stage2资源。

## 协议、晋级与报告

ETTh1 P4，96→96，原三组测试mask。seed2021、batch128、FP32；Stage1/2各100轮，lr0.001/0.0001、weight_decay0；Stage1最终全局缺失MSE+0.1 retrieval、specialist exposure0.2。Stage2只读历史key/库。

每条件按原固定验证MAE选checkpoint，最早轮次处理完全相同指标。最终报告各条件预测MSE/MAE、修复MSE/MAE、选定轮次、三组测试均值与总体std、完整流程时间、各阶段时间、allocated/reserved GiB、参数数、设备/并发、教师耗时与覆盖率。

新条件晋级仍要求相对保存v29-r1验证预测MSE严格低于0.7499365438950035、MAE不高于0.5840456761470457。若多条件通过，按验证MAE、MSE、额外训练时间、固定A/B/C顺序择优。没有通过则保留旧版。每条件锁定并验证重放后立即测试既有三组位置一次，不以测试成绩改变后续条件。长训练按用户要求每5分钟检测。

机制结论分别判断：B对A是否改善；C对B是否在同修复系数下改善。单训练seed和三组缺失位置只能提供本协议下的效果证据，不能宣称统计显著。若只改善修复而不改善预测，则拒绝当前收益加权设置。

## 实现边界与验证

收益计算、权重归一化和修复保留损失作为独立训练工具模块；现有Stage2 loop接入显式训练模式标识，旧模式默认保持不变。新增三个配置和独立runner，manifest/checkpoint记录模式、warmup10、repair_weight0.05、teacher previous_epoch_final、subset16、42区域及权重规则。旧加载器保持兼容，新加载严格校验身份及资源归属。

必要测试：替换只修改缺失原坐标且覆盖全部patch副本；可见值/mask/stats/padding不变；无缺失/全负/极小正收益有限；权重均值1且梯度停止；均匀权重还原全局MSE；教师整epoch不变且下一轮更新；标签不进入模型输入；H库/key无变化；相同初始化/各自optimizer；选模无测试依赖；资源包含教师计算。先CPU功能验证及真实batch128 CUDA短预检，再冻结源代码与配置，运行完整正式实验。

不做本轮范围外的因果图、预测头替换、可部署评分器、专家扩容或动态次数分配。局部输入替换只支持固定模型干预解释，不主张真实变量因果关系。
