# 预测敏感位置恢复：固定权重干预诊断与后续设计

日期：2026-10-03。状态：只读诊断已完成；后续训练设计为建议，尚未执行。没有新增训练、修改选模或使用测试集。

## 为什么要拆开问题

用户提出不同回溯位置的修复对未来预测价值不同，应将专家更多用于对预测有用的信息恢复。现有证据支持检验该假设，但原v30成绩涉及两个阶段：0.205550是Stage1修复权重；最终预测采用Stage2权重，其修复MSE变成0.879193。位置分配、修复微调后的退化及预测器与修复器共同适应需分别诊断。

Stage2已经通过最终预测MSE+0.2 MAE监督全部可训练组件，当前不足是缺少显式的位置级收益评估和修复保留约束。此前v17按整变量平均损伤patch路由权重，并以单专家对整变量未来预测的收益监督；其失败不等同于位置级收益监督失败。

## 诊断操作

加载v29-r1、v30 4层8组各自Stage1与Stage2选定权重，共四个修复来源；使用两个已经训练好的Stage2预测器，形成八个组合。预测器均冻结，交叉搭配仅用于机制诊断，不属于重新训练后的正式模型成绩。

在原固定验证集全部2688窗口上，将96点历史按六个不重叠16点区域×七变量划分为42个区域。每次只将一个区域中的缺失值替换为历史真值；可见值、原掩码、query mean/std、validity、其他区域、所有网络参数均固定。同一时间坐标在重叠patch中的全部副本一并修改，避免只改某个patch副本。

定义区域修复收益：

`Delta_g = MSE(f(repaired_history), future) - MSE(f(history_with_region_g_restored), future)`

正值表示补正该区域能降低当前固定预测器的误差，负值保留。该量同时包含当前修复误差与预测器对该误差的响应，是局部可修复预测收益，不是与误差大小无关的纯敏感度。另记录MAE、四个未来24步区间、每窗口区域收益及受损窗口中的正收益比例。

还测试全部缺失位置恢复为真值，但保持原缺失mask和原query统计量；这不是通常clean模型的结果，也不是严格性能上界。多个区域的效果不可直接相加；预测器的非线性和区域交互可使全部恢复与单区域恢复的效果不同。重叠验证窗口也不是独立样本。

## 因果诊断的准确范围

上述干预确定了固定模型在指定输入替换下的预测损失变化，可以用于模型机制归因。它没有识别电力系统中变量之间的真实因果关系。后者需要可识别的结构假设、时间滞后结构、混杂因素处理等额外证据。

历史真值和未来标签仅用于这次验证诊断；后续用于训练评分器的收益标签须在训练集构造，推理评分器只能使用可见历史、缺失mask和专家证据。梯度、注意力或路由权重本身不足以替代实际干预收益；梯度近似可降低代价，但应在独立验证区域与真实替换效果对照。

## 下一步实验设计建议

### 1. 首先检验位置加权是否有独立收益

从保留的单轮v29结构出发，预测头架构沿用现有接口。共同的Stage1初始化及Stage2预算下，比较三组：

| 训练条件 | 目的 |
|---|---|
| 现有预测损失 | 参考 |
| 预测损失＋均匀修复保留损失 | 判断修复能力保留本身的作用 |
| 预测损失＋位置加权修复保留损失 | 判断位置价值能否在同一修复约束强度下进一步改善预测 |

位置加权损失可写为 `sum(hidden * w * global_repair_error^2) / sum(hidden)`，使缺失位置权重平均为1，保留正权重下限并限制极大权重；均匀与位置加权组使用同一修复系数，避免只因约束总量不同而得出位置机制有效。权重及收益教师的目标停止梯度，避免权重通过压低困难位置权重来降低训练损失。

诊断中已有预测器只作研究控制。正式从头实验应在本次训练预算内学习预测器/收益教师，将其时间与显存计入报告，不能无说明复用既有最佳模型作为免费教师。可在本次Stage2内用预先固定的warmup与滞后冻结快照构造训练收益标签；这一具体设置需在正式运行前固定。

### 2. 评分器学习预期修复收益

训练标签优先来自“修补该局部后未来误差实际下降多少”，并保留负收益样例。输入可用当前patch状态、可见性、H匹配误差、V来源信息、T上下文及专家分歧；不读缺失真值或未来标签作为模型输入。还须检验纯模型敏感度、当前修复难度与可获得收益之间的差异，不能仅以大梯度或大重建误差决定投入。

### 3. 再把收益转成专家分配

在位置加权独立有效后，将预期正预测收益用于H/V/T/none路由，以及额外修复轮次或专家组分配。控制组包括均匀、随机、仅修复难度、仅位置近远分配，并在相同额外计算预算下比较；修复与预测MSE/MAE、完整时间、峰值显存都报告。模型的重叠patch需要按原时间坐标处理覆盖权重，不能重复计算同一缺失坐标的重要性。

预测器共同训练的影响单独做冻结/联合或clean-reference监督对照；与位置加权实验分开，避免一次修改多个因素后无法解释收益。三个固定测试位置仍仅用于各模型自己的权重锁定后的结果报告。

## 相关研究与论文定位

- [Task-oriented Time Series Imputation Evaluation via Generalized Representers，NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/file/f88264fcc54775ee1706116e90fe351a-Paper-Conference.pdf)：按下游预测价值评估并组合插补策略，重点涉及缺失训练标签对预测的影响，和我们的缺失回溯输入场景不同。
- [Is Precise Recovery Necessary?，2024](https://arxiv.org/abs/2411.09928)：面向测试时变量子集缺失，采用任务导向插补及联合学习，说明“插补服务预测”本身已有研究。
- [Revisiting Multivariate Time Series Forecasting with Missing Values，2025预印本、2026修订](https://arxiv.org/abs/2509.23494)：CRIB直接从部分观测输入学习预测表征，讨论插补误差对预测的影响。

因此论文贡献应由实验支持具体到：缺失回溯窗口的位置级预测收益、不同历史/变量/时间证据的作用，以及按收益分配修复计算。当前只读诊断支持继续研究这些机制，尚未证明拟议模块改善预测或构成新颖性结论。
