# E23 v36：重叠 patch 的逐位置加权融合

2026-10-04 完成。固定验证未超过单轮纯 MSE 对照或现有最佳方案，**保留 E23-v31-B**。三组测试已在 checkpoint 锁定后完成。

## 改动与固定设置

v34 的历史上下文检索、v35 的点级 T 编码均未通过固定验证，因此本轮沿用原 H、原 T、原 V 和单轮 T→V→H，只改修复器的重叠融合。每个 patch 根据最终 64 维修复 latent、原可见值、原 mask、validity、路由权重和 rho，由 117→32→16 的 MLP 输出 16 个位置权重。权重为 `exp(2*tanh(logit))`，在同一时间坐标的多个 patch 副本之间归一化，然后加权还原 96 点序列。可见值仍被硬性保持。

新增 4432 参数，修复器共 139753 参数。最后一层零初始化，初始权重全为 1；真实 CUDA 检查确认初始恢复函数与原均匀平均严格一致，新增模块初始化隔离 RNG。

预测头保持原 PatchTST D16，35427 参数，explicit_v1 接口不变。预测头源码、Stage 2 训练函数 AST 和预测头初始权重 SHA 均已核对一致。

独立训练一次，seed 2021、batch 128、FP32；Stage 1/2 各跑满 100 轮，Adam lr 0.001/0.0001、weight_decay 0。Stage 1 为原全局尺度修复 MSE + 0.1 检索损失，specialist exposure 0.2；Stage 2 为原纯预测 MSE，固定验证 MAE 选 checkpoint。没有增加损失、辅助预测器或冻结日程。

ETTh1 P4，回溯 96→预测 96，缺失块起始率 0.10、块长 8、允许重叠；起始率不是缺失坐标比例。三组测试 seed 为 2021/2026100201/2026100202，每组 2688 窗口、1806336 预测坐标。测试结果不参与本轮裁定。
