# E23 迭代回顾、20组缺失位置说明及后续场景比较

日期：2026-10-05。根据已保存的实验报告、CSV和候选索引整理。本文件汇总既有结果并提出下一轮场景顺序；本次整理没有启动训练。

## 1. 演进主线

版本号包含未晋级的试验分支，不能理解成每一版都加入了最终模型。早期P4与后期高缺失场景的指标分开阅读。

| 阶段 | 主要改动与实验发现 | 对最终方案的影响 |
|---|---|---|
| 初版 → v2/v3 | 建立H历史原型、V跨变量、T时间上下文三专家；修复宽度由16增至64，预测器仍为原PatchTST D16。宽度64首次选定测试MSE为0.429694；v3改为按验证MAE选模，同一固定测试mask上为0.427265/0.434449。 | 保留D64修复表示；预测头结构与配置不变。 |
| v11/v12 | Stage2引入MSE+0.2MAE；V由固定全局来源选择改为随当前窗口和patch选择四个来源。 | 保留窗口条件V和混合预测损失。 |
| v13–v27 | 探索H重排、历史/当前分组、隐式预测接口、多头三专家及其他融合方式。 | 这些试验没有形成持续优于v12的替代方案，不全部带入最终版本。 |
| v28 | 修正Stage1损失与选模尺度：采用训练集全局标准化的缺失坐标MSE，消除小可见标准差的逆方差放大。 | 后续一直使用global_mse_v1；这不是物理原始单位的MSE。 |
| v29 | 比较单轮与三轮T→V→H条件读取；单轮预测优于三轮。 | 保留单轮条件读取；最终模型没有连续执行三轮修复。 |
| v30 | 比较1层8组、4层1组、4层8组三专家。4层8组Stage1修复MSE降至0.205550，但Stage2后修复和预测均变差。 | 说明增加容量改善Stage1重建，不保证最终预测收益；该大模型未进入最终方案。 |
| v31-B | Stage2加入均匀缺失坐标修复保留约束，减少联合预测训练对修复的破坏。位置收益加权C未超过B。 | 保留均匀修复约束；最终模型不含C的区域真值替换或位置收益教师。 |
| v32–v41 | 探索辅助预测、历史库、点级恢复；v40增加最后32点精修，v41比较完全冻结与慢速更新修复器。 | 保留最近32点精修；慢更新改善了当时的验证门槛，冻结实验也显示修复漂移值得控制。 |
| v42–v45 | 比较纯MSE、更多更新、非重叠修复patch及16/8/4粒度、CNN/注意力末端精修。 | 未形成超过既有开发参考的稳定替代；最终保留修复P16/S8，并处理重叠输出的融合。 |
| v46–v58 | 在高缺失场景加强可见窗口CNN、点级专家路由、重叠置信融合、八头候选读出、稳健修复坐标和最近32点均值校正。 | 最终保留这些通过逐步验证的组成；带统计调制的变量注意力、变量校准、历史key多样化等分支未保留。 |
| v59–v63 | 额外时间证据、补齐方式、尺度下限、更多Stage1更新未通过升级；v63在可见CNN后加入两层不带统计调制的整窗跨变量signature注意力。 | v63是原固定验证双指标门槛下的保留父版本。 |
| v64/v65 | 在v63结构上完全冻结Stage1修复器，只训练原预测器；检查2021–2024四个训练种子，四个冻结MAE版本的测试均优于同seed慢更新版。 | 冻结成为当前候选的Stage2策略。v69的seed2023依据既有冻结控制的固定验证MAE预先选定。 |
| v66–v68 | 直接点级上下文修正、冻结后的纯MSE控制及冻结点修正。 | 均未进一步超越原冻结控制；v69不含v66点级上下文修正。 |
| v69 | 在原窗口CNN和signature注意力之间加入零初始化的变量×时间位置参数，新增43008参数；完成Stage1后完全冻结修复器。 | 在既有20组和锁定后的新20组缺失位置上，MSE和MAE均低于固定T1。 |

早期P4约57%缺失、单mask/三mask、不同训练seed的数字不与后期约73%缺失表直接比较。v3与v12的早期单mask结果也不能替代20组均值。

## 2. 高缺失阶段的关键结果

以下全部为ETTh1 96→96、起点率0.15、块长8、允许块重叠、同一旧20组缺失位置；实际缺失72.9252%。每行各自按验证选checkpoint。种子变化和更新策略列出，因此整体演进不是单一结构的严格消融。

| 模型 | 训练seed | 主要变化 | 测试MSE | 测试MAE |
|---|---:|---|---:|---:|
| v41-slow | 502 | 最近32点精修、修复器慢更新 | 0.455761 | 0.453554 |
| v47 | 502 | 可见CNN前端并冻结前端 | 0.443177 | 0.441950 |
| v48 | 502 | 点级专家路由 | 0.438415 | 0.438458 |
| v54 | 502 | 八头候选读出基础上的稳健修复坐标 | 0.431608 | 0.435215 |
| v58 | 502 | 近期均值校正与Stage1均值监督 | 0.428037 | 0.437745 |
| v63-MAE | 502 | 两层无统计调制的整窗变量注意力 | 0.425347 | 0.432369 |
| v64-retained-frozen-MAE | 502 | v63整个修复器冻结 | 0.417380 | 0.419302 |
| v65-seed2023-frozen-MAE | 2023 | 同结构换训练seed，仍完全冻结 | 0.415625 | 0.417999 |
| v69-seed2023-legacy-MAE | 2023 | 新位置参数，Stage2仍部分慢更新 | 0.419083 | 0.432576 |

位置参数的同seed冻结匹配参考是v65-seed2023-frozen-MAE：Stage1修复MSE从0.270102降至0.242310，最终预测从0.415625/0.417999改善至0.408509/0.413151。这里Stage1与预测成绩分别报告，不把修复误差当作预测误差。

v69修复器共420973参数；原PatchTST预测器仍为35427参数。候选的八头是点级候选读出，整窗signature模块另有64个特征通道注意力头；没有八个独立完整三专家组。

当前候选完整训练14.20分钟、峰值allocated/reserved为4.622/6.402GiB；T1为10.85分钟、1.779/2.699GiB。精度领先，当前训练时间和显存没有领先。

验证保留与开发胜出须分别标注：v69冻结版验证MSE/MAE为0.766868/0.583212，未通过相对v63的原双指标升级门槛；v63验证为0.742569/0.582020。v69是开发测试胜出且新位置复核通过的候选，原验证门槛保留父版本仍为v63。

## 3. “旧20组”与“新20组”是什么意思

一组指一套完整测试缺失mask，覆盖全部测试窗口和变量。例如，同一个96点回溯窗口在第1组缺失一批位置，在第2组缺失另一批位置；每次仍预测同一段未来96点。它不表示20个样本、20次训练或20个数据集。

| 项目 | 旧20组 development20 | 新20组 fresh20 |
|---|---|---|
| 缺失生成参数 | 起点率0.15、块8、允许重叠 | 完全相同 |
| mask种子 | 2026100401–2026100420 | 2026100501–2026100520 |
| 实际平均缺失比例 | 72.9252% | 72.7710% |
| 数据与未来目标 | 同一ETTh1测试时间段 | 与旧20组相同 |
| 用途 | 已用于观察多轮开发结果 | v69权重、配置、源码锁定后才生成，用于复核 |
| 是否重新训练 | 每模型的同一选定权重测试20次 | 直接使用相同权重测试，没有重训 |
| 模型间位置是否一致 | 同一组E23与T1共享mask | 同一组E23与T1共享mask |

两个实际缺失比例的细微差异来自随机位置及块重叠，生成参数未改变。这里0.15是缺失块起点率，不是15%的最终点缺失率。

| mask集合 | E23-v69 MSE | E23-v69 MAE | T1 MSE | T1 MAE |
|---|---:|---:|---:|---:|
| 旧20组 | 0.408509 | 0.413151 | 0.411002 | 0.427785 |
| 新20组 | 0.409623 | 0.414195 | 0.416530 | 0.430541 |

新20组MSE胜14/20、MAE胜20/20。均值/标准差描述同一权重对缺失位置的敏感性，不是20个训练种子的统计。新位置增强了当前场景的复核证据，但仍是同一测试时间段；不等于新数据集或独立未来目标。新20组现在已经观察过，继续开发时不能再把它称为未见的确认集。

## 4. 后续其他缺失参数比较建议

目标：检验已锁定v69方案能否跨缺失参数保持优势，而不是在每个场景重新挑结构、训练配方或有利seed。

| 建议顺序 | 起点率 | 块长 | 既有20组实际缺失 | 检验内容 | 已有T1 MSE / MAE |
|---|---:|---:|---:|---|---:|
| 1 | 0.10 | 8 | 57.28% | 回到原始难度，检验高缺失改良是否仍有效 | 0.388984 / 0.417673 |
| 2 | 0.20 | 8 | 83.51% | 更少可见证据时是否仍能工作 | 0.458344 / 0.446864 |
| 3 | 0.10 | 16 | 81.94% | 更长连续缺失时的恢复和预测 | 0.527359 / 0.476055 |
| 已完成参考 | 0.15 | 8 | 72.93% | 当前高缺失开发场景 | 0.411002 / 0.427785 |

建议执行口径：

- 固定ETTh1数据划分、训练集标准化、96→96和原PatchTST预测器结构/配置。
- v69各新场景分别从头训练Stage1与Stage2各100轮，保持当前D64、P16/S8、位置参数、seed2023、原损失与完全冻结策略。调整该场景缺失生成配置；不逐场景搜索seed。
- Stage1仍按全局缺失MSE选checkpoint；Stage2按固定验证MAE选主checkpoint，另存MSE版本作透明的次要报告。主表统一使用MAE选择结果。
- T1沿用作者配置和seed502。三个场景已有T1选定权重与资源记录，核验checkpoint/config/mask身份后复用；不为这轮重训相同T1。各模型seed不同如实标注；这轮不是多训练种子结论。
- 优先共用每场景已有20组mask，便于同时比较T1及旧v41-slow；每组两模型位置完全一致。各场景验证决定和checkpoint锁定后再评估测试。
- 报告平均MSE/MAE、位置标准差、配对胜出组数、完整两阶段训练时间、峰值allocated/reserved；附Stage1与Stage2修复MSE及最近32点诊断。
- v69仍为MSE+0.2MAE且完全冻结，T1为纯MSE联合训练，训练方案差异持续披露。共同预测头架构不变，不能把性能差异全部归因于位置参数。
- 若正式论文需要训练稳定性结论，再对预先固定的一组训练seed重复整个模型训练；不在每个场景取最低测试误差的seed。

0.20/8和0.10/16实际缺失比例接近但并不完全相同。这两项可检验不同缺失形态的适应性，不能单独隔离块长的纯因果效应。表内T1数字均为已有旧20组成绩；新mask库若另行生成，T1也需用固定权重重新测试，不能混用两个库的均值。

当前v69源码保存在冻结隔离目录及源码归档，尚未合入主E23；后续新场景应从该冻结来源建立新的隔离实验，保留本轮权重和记录。
