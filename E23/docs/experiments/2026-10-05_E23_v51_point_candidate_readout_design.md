# E23-v51：逐点读取未聚合专家候选

状态：两阶段100轮及20组测试完成；61项检查、GPU预检查和最终审计通过。

用户授权继续迭代直到超过T1。沿用ETTh1 96→96、起点率0.15/块长8/允许重叠、20组已有测试位置，平均缺失72.9252%；训练seed502、固定验证mask2021。不修改原PatchTST预测头。起点采用上一轮测试前已按验证保留的v49；v48仍为上一轮开发测试最低误差版本，两个参考都保留。

## 当前假设及单项改动

v48已细化H/V/T专家间的逐点选择，但各专家内部的4个历史、12个变量、10个时间候选仍先按标量权重聚合。v51保留原三专家、原逐点路由和重叠聚合，在原数值decoder之后加入独立逐点候选读取分支。

每个patch的16个位置构造不同query，输入原可见CNN逐点上下文64、融合潜表示64、原可见值/mask/位置/邻近可见距离5、patch相位1、当前全局尺度数值估计1、原逐点专家权重4及可用条件4，共143维。原始候选message、quality、专家类型构造key/value；8头×8维，总64维。每个位置对26个候选和零值null token计算注意力，原逐点专家权重×原候选权重作为先验。候选资格、singleton曝光和禁用专家保持。

读取结果与point query经过128→64→1 MLP生成全局训练标准化尺度的数值修复增量。仅作用于原隐藏有效点；没有可用候选则增量为零。增量先加入原patch估计，再经过原置信度折叠和最后32点refiner。全局增量除以原visible-only query_std转换到原接口。最后线性层零初始化，新增参数构造隔离RNG，严格保持原模型初始函数和预测器初始化。新增31937参数，总修复参数259628。

这是直接读取未聚合候选的数值恢复分支，与旧patch级多头路由不同；它没有改变H检索范围、完全缺失H资格或候选数量。

## 训练、选择和评估

Stage1从头100轮，batch128/FP32、lr0.001、全局隐藏MSE＋0.1原检索损失、specialist exposure0.2，按验证修复MSE选模。Stage2从头100轮，batch128/FP32，原MSE＋0.2MAE、第11轮起0.05均匀修复保留，冻结窗口CNN前端和原H检索key/库，其他修复参数lr1e-5、原预测器lr1e-4。Stage2按固定验证MAE选权重。

验证预测MSE低于v49且MAE不更差才作为下一轮父版本；决定在测试前保存。权重锁定后测试同一20组位置。相对T1验证及测试结果均单独报告；开发测试多次使用，不将一次开发胜出称为最终论文证明。若达到目标，将在模型锁定后使用新的同场景位置作独立确认。

每次报告平均MSE/MAE、20位置标准差、完整两个训练阶段准备/训练/验证/保存时间，以及allocated/reserved显存峰值。测试和额外诊断另计。同一RTX5090顺序运行。

保存修复全窗/近期/边界MSE及近期水平/趋势、逐点候选注意力熵、null权重和同patch位置变化，用于确认机制启用。它们不能单独证明因果收益。
