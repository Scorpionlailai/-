# E23 模型构成、迭代脉络与实验设置总览

日期：2026-10-06。本文汇总 E23 从初版到当前已完成实验，并区分不同缺失场景下的候选和基线。结果均可由文末实验记录复核。

## 1. 当前结论

“最佳模型”须指定缺失场景。对本轮重点的 ETTh1 96→96、起点率 0.10、块长 16、实际缺失约 81.94% 长缺失场景，当前 E23 保留模型为 **E23-v77**。它是 E23 在该场景已测候选中最好的，但还没有超过固定 T1：同一批 20 组测试位置上，v77 的 MSE/MAE 是 **0.551167/0.493097**，T1 是 **0.527359/0.476055**。

对齐历史原型键坐标的 v78 已完成 100+100 轮，并测试同一 20 组位置。它的最终预测比 v77 略差，且验证 MAE 未通过晋级门槛，故仍保留 v77。停止本轮工作时没有活动中的训练进程；v79 没有实现或训练。

在约 72.9% 缺失、起点率 0.15、块长 8 的另一场景，v69 在保存的旧 20 组和后来锁定的新 20 组上均超过了相应 T1 结果。该结果不能与 81.94% 缺失场景的表格混为一个排名。约 56.7% 缺失的标准 P4 场景里，v31-B 五种子对照仍落后于 T1。E23 目前没有证据支持“所有缺失场景或所有种子均优于 T1”。

## 3. 当前保留模型 E23-v77 的完整构成

### 任务与接口

- 输入 ETTh1 的 7 个变量，每个样本有 96 个历史点；输出未来 96 点。缺失只作用于回溯输入。
- 前端修复 patch 长 16、步长 8，因此相邻 patch 重叠 8 点。修复后以置信度融合重叠候选，并在观测坐标硬性保留原始可见值和原 mask。
- 最终预测头仍是原 PatchTST，`d_model=16`、4 个 attention heads、`d_ff=128`、3 个 encoder layers，参数共 **35,427**。Stage 2 从固定 seed=2023 重新初始化该头；其初始参数 SHA 与既有 E23 记录一致。预测头没有另加层或改接口。

### 修复器：宽度 64，单轮顺序取证

E23-v77 有 **424,238 个修复器参数**。核心状态宽度为 64，单轮证据读取顺序为 **T → V → H**：先读当前变量的时间证据，再依更新后的表示读当前窗口中其他变量，最后查训练历史原型。三个专家产生的是候选证据，点级路由可以为它们分配权重，也可以选择保留原表示。

| 子模块 | 当前实现 | 用途与边界 |
|---|---|---|
| 可见窗口前端 | 两层 window CNN，宽度 64、核长 7/31、膨胀率 1/2、残差初始尺度 0.1、稳健局部可见值归一化；只提供 latent 上下文 | 用当前 96 点可见历史建模多尺度局部形状和跨变量上下文 |
| 整窗变量/时间上下文 | `signature_plain_pos_v3`，宽度 64、2 个 attention blocks、沿 64 特征轴 64 heads、head dim 96、位置参数长度 96；无统计调制 | 为变量—时间位置提供上下文；它是修复器内部注意力，不是预测头 |
| T 时间专家 | 局部半径 2、时间距离分带边界 2/4/8/16 | 按当前变量可见时间点形成时间候选 |
| V 变量专家 | 每个目标最多取 4 个来源；来源分数随窗口/patch变化；读取偏移 -1/0/+1 的相邻 patch | 利用当前窗口可用的跨变量证据；数据相关性不等于因果关系 |
| H 历史专家 | 训练期仅由完整可见原始 patch 构建在线原型库；同变量 top-4，阈值 0.7，按可用历史和质量筛选 | 为当前局部片段寻找可用历史模式。完全缺失、没有可见 query 的目标 patch 仍不能使用 H |
| 点级候选读取 | `eight_head_v1`，每个候选读出分支宽度 64，8 个读出头 | 将多种候选转成点级残差；“八头”不是八套完整三专家模型 |
| 点级路由 | `pointwise_v1`，宽度 64，94 项 query 特征，专家为 none/H/V/T，logit 有界 ±2 | 对每个点仲裁候选贡献，并允许 none 保留原始 latent |
| 末端修复 | 32 点范围、宽度 64 的 point residual refiner；从稳健局部坐标恢复 | 补足 patch 级输出与点级预测需要的粒度 |
| 重叠聚合 | 宽度 32、84 个重叠特征的 `confidence_v1`，融合权重对数界限 ±2 | 对 P16/S8 重叠 patch 产生的多个值作置信度加权融合 |
| 近期均值修正 | 原 mean v1（13,249 参数）加全变量 global mean 分支（49→64→1，新增 3,265 参数） | 读 7 个变量真实可见的 whole-96 / recent-32 均值、最近值、可见比例、标准差及目标变量身份；输出全局标准化坐标中的有界 level 修正（±2），只作用于最近 32 点缺失位置并受 share cap 4 限制 |
| 长缺失结构项 | Stage 1 对原 96 点回溯中长度至少 16 的连续缺失段加均值与趋势约束，各权重 0.2，按缺失坐标数加权 | 着眼长缺失段的水平和趋势；它不改预测头 |

H 仍使用 v77 的 `legacy_v1` 坐标逻辑。v78 尝试把历史键训练和查询改成历史库所用的全局标准化坐标，虽然 Stage 1 修复 MSE 有小幅改善，最终预测没有改善，故该改动不属于当前保留模型。

### 两阶段训练

- **Stage 1：** seed 2023；100 轮、batch 128、FP32、Adam、学习率 0.001、weight decay 0。每轮 66 个 batch，共 6,600 次更新。最小化训练集全局标准化坐标上的缺失值 MSE、0.1 retrieval loss 和长缺失段结构项；按固定验证集全局缺失修复 MSE 选权重。specialist exposure 为 0.2。
- Stage 1 使用独立初始化的 PatchTST 辅助预测器（seed 2022，35,427 总参数，35,424 可训练），只把 future forecast loss 以 **0.05** 权重加入 Stage 1；前 10 轮先训练辅助头，不让预测梯度回到修复器。此辅助头用于训练监督，最终丢弃。
- **Stage 2：** 从原始 E23 初始 seed 2023 创建新 PatchTST，100 轮、batch 128、FP32、学习率 0.0001；训练预测头，修复器完全冻结（218 个修复状态张量逐位冻结）。损失是 forecast MSE + 0.2×forecast MAE，并保留配方里的 uniform repair 项；MAE 为主 checkpoint 指标、MSE 为同轨迹次指标。MAE/MSE 两个版本不是两次独立训练。
- Stage 1+2 全流程 **870.52 秒 / 14.51 分钟**。峰值 PyTorch allocator allocated/reserved 为 **4.591/8.701 GiB**；它不是整张卡的占用。RTX 5090，GPU UUID `1315e15c-d657-e61f-bde5-6e0b38e6e54b`。

## 4. 从最初 E23 到当前模型的改良路线

版本号中包括许多被验证淘汰的分支。只有通过当时预先规定的验证门槛，或在明确的后续场景里产生可重复参考的改动，才被保留；不能把所有版本说成一路叠加。

| 版本/阶段 | 具体变化和观测 | 对当前模型的影响 |
|---|---|---|
| 初版、v2、v3 | 建立 H 历史、V 跨变量、T 时间三专家；修复 latent 从 16 加宽到 64，预测头仍为 PatchTST D16。宽度 64 的 MSE 选模测试为 0.429694/0.437349；v3 改用验证 MAE 选权重后为 0.427265/0.434449 | 奠定“64 维修复器 + 原预测头”基础。早期使用单个/少量固定缺失位置，v3 选择方向是在查看过 v2 测试结果后提出；属于探索证据 |
| v11–v12 | Stage 2 损失改成 MSE+0.2MAE；V 的来源从全局固定改成随当前窗口和 patch 选择 4 个来源。v12 验证 MSE/MAE 0.745448/0.588212，固定测试三组均值 0.427463/0.431356 | 混合损失和当前窗口 V 选择留在后续基线中 |
| v13–v27 | 测试 H 重排、历史/当前分组、隐式预测、多头专家与融合策略 | 没有一条分支稳定替代 v12；未全部继承 |
| v28 | 将 Stage 1 修复损失和选择尺度修正为全局 train-standardized hidden-coordinate MSE，避免局部标准差很小时窗口归一化误差主导选模 | 后续主线使用 `global_mse_v1` |
| v29 | 比较单轮与三轮重复 T→V→H 条件读取；单轮优于三轮，三轮结果显示中间修复更好不保证最终预测更好 | 保留单轮顺序条件更新，没有做连续三轮推理 |
| v30 | 比较 1 层×8 组、4×1、4×8 并行完整三专家。4×8 的 Stage 1 修复 MSE 达 0.205550，但 Stage 2 修复和预测都变差，测试 MSE/MAE 0.532782/0.521352 | 说明单纯堆叠扩大容量不足以提升预测，未采用该大模型 |
| v31-B | Stage 2 第 11 轮起增加 0.05 均匀缺失坐标修复约束，抑制联合预测更新造成的修复漂移。位置收益加权 C 未超过 B | 早期方案中保留修复约束；当前 v77 的 Stage 2 已改为冻结修复器 |
| v32–v45 | 研究 Stage 1 辅助预测、刷新轮次、上下文历史库、点级时间修复、重叠 patch 融合及 patch 粒度 | 最近 32 点修复与重叠融合等成为高缺失阶段的基础；三轮刷新、非重叠粒度等未统一胜出 |
| v46–v58 | 高缺失下增可见 CNN、点级专家路由、稳健修复坐标、八头候选读出、近期均值监督/修正 | 成为 v69 之后修复器主体；变量校准等旁支不保留 |
| v59–v63 | 测试额外时间证据、padding、尺度下限和更多更新；v63 增整窗无统计调制的变量注意力 | v63 成为后续位置参数迭代的起点；失败分支不进入当前模型 |
| v64–v69 | 多 seed 比较冻结/慢更新 Stage 2；v69 在 CNN 与 signature context 中加入零初始化变量×时间位置参数，新增 43,008 修复参数，并冻结 Stage 2 修复器 | 在约 72.9% 缺失的 sr015/bl8 场景，v69 用 seed 2023 在旧/新 20 位置上均胜固定 T1。它的固定验证成绩未满足原始 v63 晋级门槛，因此定位为该场景的开发/新位置候选，不改写验证裁定 |
| v70–v72 | 在长缺失场景依次加强 TV/H 证据、观测校准及长缺失段均值/趋势监督；v72 相对 v69 小幅验证晋级 | v72 成为 sr010/bl16 的迭代父版 |
| v73–v75 | 段级注意力、注意力移位、前端全局 level 分支 | 都未通过验证门槛；其中 v75 的预测很差，未保留 |
| v76 | 首次在 Stage 1 使用独立辅助预测头，权重 0.05、warmup 10 轮、seed 2022，训练后丢弃；全局 hidden repair MSE 仍是 Stage 1 选模指标 | 在长缺失场景通过固定验证晋级，测试也有小幅提升 |
| v77 | 在近期均值修正器旁增加读取全变量全局可见统计的零输出分支，49→64→1，新增 3,265 修复器参数 | 再通过验证晋级，成为当前长缺失场景保留模型；测试仍未超过 T1 |
| v78 | H 历史键训练/查询全局坐标对齐，0 新参数 | Stage 1 修复更好、验证预测 MAE 和测试预测退步；未晋级，明确保留为负结果 |

## 6. 当前和既有多随机种子实验

### 训练随机种子

- 最初 E23 v2/v3、v11/v12 主要用训练 seed=2021；这些早期实验以单训练运行和固定/少量缺失位置为主。
- v31-B 与 T1 做过更严格的 **5 次独立训练**：训练种子 102、202、302、402、502；每个 checkpoint 都在相同的 20 个新 mask 上测试。每个模型先训练一次后测 20 mask，mask 标准差与训练种子标准差分开计算。E23-v31-B 均值 MSE/MAE 为 **0.414918/0.430711**；T1 为 **0.396421/0.421283**，T1 五个种子均更优。该实验对应约 57% 缺失的标准 P4，不是本次 81.94% 场景。
- v69 的约 72.9% 场景使用 E23 seed=2023，T1 沿用作者 seed=502，均为各一套训练权重；通过分别锁定旧 20 和新 20 个位置测量位置波动，**没有**对 E23 训练 seed 重复五次。
- 本次 81.94% 场景中，E23 v69/v72/v76/v77/v78 都使用固定 seed=2023，各一个训练重复；T1 是固定作者 seed=502 的既有模型，不是本轮重训。当前场景的标准差因此只度量 mask 变化，不度量训练随机性。

### 缺失掩码随机种子

- 当前固定场景参数是 `start_rate=0.10`、`block_len=16`、允许生成块重叠、seq/pred=96、7 变量。**0.10 表示块起点密度，不是最终点缺失率**；实测平均评测缺失为 0.819388（81.94%）。
- 同一批旧 20 组开发 mask 的生成种子为 **2026100401–2026100420**。E23 候选与 T1 共用完全相同的 mask，每组 2,688 个评测窗口。不同 mask 的实际缺失比例约 81%–83%，均值约 81.94%。
- 另提前封存了 20 组确认 mask，种子 **2026100601–2026100620**，实测平均缺失约 81.76%。因为 v77/v78 尚未同时达到固定验证与旧 20 组的 T1 目标，这批确认 mask **没有评分**，也没有用其挑选版本。
- 当前固定 validation mask SHA、旧 test bank SHA 及每个模型的 checkpoint/config SHA 均在各报告和机器可读记录中锁定。

## 7. 解读边界和可复核文件

1. 当前 v77 是“81.94% 长缺失场景的 E23 最佳候选”，不是所有缺失条件下的全局赢家；它仍落后 T1 的 MSE 和 MAE。
2. 旧 20 组位置在连续版本开发中重复曝光，属于开发集。v69 曾有另一个封存 20 位置复核，但它不等于新数据或新未来区间；本次长缺失封存 20 组还未解锁评分。
