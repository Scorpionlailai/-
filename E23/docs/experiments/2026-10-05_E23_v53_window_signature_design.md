# E23-v53：恢复前端的整窗变量注意力

状态：两阶段100轮及20组测试完成；16项检查、GPU预检查和最终审计通过。

## 顺序与假设

v51修复和验证预测改善，但20位置开发测试回落；v52候选身份/尺度分支未通过验证，测试亦回落。按既定验证父版本决定，本轮基于v51，仅增加恢复前端的整窗变量交互。v48仍是已有开发测试中表现最好的E23，作为参考保存；不覆盖任何旧权重。

当前窗口CNN对变量独立处理，V只在有限的局部候选上交互。新的前端以整个96点可见轨迹形成动态变量关系，再将上下文送入原H/V/T、逐点路由和候选读出。几何借鉴官方T1的variable attention：feature channels充当attention heads、整窗时间特征作为head vector，参见已保存官方`artifacts/upstream/T1/models/T1.py`的Attention与T1Block。此部分不宣称为独立发明，也不复用T1训练权重。

## 唯一新增前端分支

原可见窗口CNN两块、width64、输入可见全局尺度值/mask/位置/前后可见距离保持。其逐点特征随后进入两个signature blocks：共享depthwise kernel5/31生成Q/K/V；64个特征头，每个以96点为向量，计算7变量之间的注意力。来源必须在原窗口存在真实可见值；加入原可见比例log先验与零值null token，屏蔽无效时间。可见缺失原值从CNN入口已屏蔽，生成值不作为新观测。

每块用原visible-only query mean/log(std)生成6×变量×64的仿射条件，MLP14→32→2688（ETTh1的7变量）；正scale限定[0.25,4]，offset限定±2，初始scale1/offset0。与T1公开SACA的概念相关，本版采用独立实现的有界条件，避免无界尺度。

注意力输出1×1投影、LayerNorm(64,96)、残差；随后64→128→64 FFN、相同归一化和残差。attention/FFN dropout0.1，残差scale初始0.001。输出投影和FFN末层零初始化，构造隔离RNG，严格保留原初始点特征、原参数、修复函数和预测头初始化。

新增283456参数，修复器总543084，完整窗口前端326656；Stage2全前端冻结，可训练修复参数仍210156。原预测头35427参数、配置与训练源码保持。原专家候选资格和singleton曝光仍执行；共享前端现可读取其他变量的原可见上下文，因此不将singleton曝光解释为隔离所有跨变量输入。
