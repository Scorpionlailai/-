# ETTh1 P4：v31-B 与 T1 的五次独立训练对照

正式实验已完成：每个模型从头完整训练 5 次；每个 checkpoint 测试同一批 20 组新缺失位置。

训练种子 102、202、302、402、502；96→96；原 PatchTST D16 预测头。选模只使用原固定验证集 MAE。原 seed=2021 权重和旧三组记录保持原样。

|---|---:|---:|---:|---:|---:|---:|

标准差为样本标准差（ddof=1）。训练标准差由各 checkpoint 的 20 掩码均值计算；缺失位置标准差由各掩码的 5 训练种子均值计算。

| 指标 | E23−T1 平均差异 | 配对交叉 bootstrap 95% 区间 | 训练种子胜出数 | 掩码胜出数 |
|---|---:|---|---:|---:|

负差异代表 E23 更好。区间用同一模型配对、训练种子与掩码两个轴分别重采样 10,000 次计算。100 个单元没有被当成独立样本；区间仅针对此固定 ETTh1 切分下的训练随机性和缺失位置变化。

完整训练时间包括入口导入、准备、全部训练阶段、验证与 checkpoint 保存，排除最终测试。所有训练顺序使用同一张 RTX 5090 GPU 1。T1 Stage 1 保留官方 batch=16/BF16/早停；E23 Stage 1 为 batch=128/FP32/100 轮；Stage 2 均为 batch=128/FP32/100 轮。具体实际轮数见逐种子 CSV。
