# Beijing sr020_bl8：R3解释实验最新结论

本页汇总2026-11-01至11-02的四轮解释实验，包含负结果和适用边界。所有下表均为 **BeijingAirQuality、sr020_bl8、训练seed2023、同20组测试mask**；不是三训练seed均值。此前R3 MSE0.122833是三seed均值，本页配对R3为seed2023的0.123941，不能混用。

粗恢复器全程固定；新增训练均为阶段二精恢复100轮、batch128、19000更新，Adam .001，原损失（全96点隐藏MAE＋0.25近32点隐藏MAE），验证全96点MAE选模；自然缺失无真值位置不监督、不计分。此处“阶段二”不是下游预测Stage2。

正式R3发布模型未因本轮结果改动。单seed结果不能证明跨训练seed显著性，20组测试mask也不是20个训练seed。不同模块差值是条件收益，不可相加为独立贡献百分比。

## 1. 候选机制：粗恢复有增量，精恢复后差距缩小

| 配置 | 粗MSE | 精恢复后MSE | 精恢复后MAE | 最终MSE较R3增加 |
|---|---:|---:|---:|---:|
| E0 完整R3 | 0.179570 | **0.123941** | 0.188432 | — |
| E1 去T | 0.187360 | 0.124086 | 0.189469 | +0.12% |
| E2 去V | 0.186331 | 0.125964 | 0.189059 | +1.63% |
| E3 去H | 0.180888 | 0.124293 | 0.188742 | +0.28% |
| E4 来源内随机选 | 0.182129 | 0.127421 | 0.188573 | +2.81% |
| E5 统一相似度检索 | **0.177548** | 0.123984 | **0.188363** | +0.03% |
| E6 容量匹配无候选 | 0.188083 | 0.124760 | 0.189678 | +0.66% |
| E8 Patch共享读取 | 0.180215 | 0.124055 | 0.188527 | +0.09% |

完整R3相对E6粗MSE降低4.53%，最终只降低0.66%。V在单来源删除中最终影响最大，但本场景不支持三个来源都具有很大最终收益。随机选较差，而统一相似度检索接近完整，不能声称专门分来源组织已明显优于普通检索。逐点读取相对Patch共享读取也未明显拉开差距。E7按用户要求不纳入。

## 2. T1追加同款精恢复：此前系统优势不能主要归于候选

| 粗恢复 | 原输出MSE / MAE | 精恢复后MSE / MAE |
|---|---|---|
| 原T1 | 0.225523 / 0.264340 | 0.129252 / 0.193203 |
| E6 | 0.188083 / 0.243393 | 0.124760 / 0.189678 |
| 完整R3 | **0.179570 / 0.235067** | **0.123941 / 0.188432** |

原T1权重来自commit `7e6b3e8f06d9081b989f90e6406a7b466ed262d6`，第90轮验证MSE选模；本轮未重训T1。SHA与原选模记录一致，原20mask MSE回放误差约3.47e-8。

T1加精恢复后MSE降低42.69%。完整R3相对原T1约45.04%的系统优势，在两者都用同款精恢复后缩小到4.11% MSE、2.47% MAE。因此精恢复有跨粗恢复器的可迁移作用；大幅系统差距不能主要归于三专家独有作用。

## 3. 简单初始化：学习式粗恢复有效，但S1有结构限制

| 初始化 | 初始MSE | 精恢复后MSE | 精恢复后MAE |
|---|---:|---:|---:|
| S0 训练标准化零值 | 1.132041 | 0.150834 | 0.200660 |
| S1 现有邻点插值 | 0.646354 | 0.185754 | 0.217121 |
| E6 | 0.188083 | 0.124760 | 0.189678 |
| 完整R3 | 0.179570 | **0.123941** | **0.188432** |

两组均完全移除阶段一网络和候选检索；精恢复独立初始化、独立训练。当前结构预算下，学习式粗恢复优于简单初始化；完整R3相对S0最终MSE降低17.83%。S0本身也强，说明精恢复有独立恢复能力，不能称其只做微小误差校准。

**S1不能用作“插值天生不如学习”的充分证据。** 固定精恢复的网络残差限制在±2；S1初值等于guide，导致另一条guide-coarse修正理论为0。固定验证集4.81%隐藏坐标的插值误差超过2，仅输出范围造成的理论验证MSE下界为0.159895。这是验证诊断，不是测试分数，也未用于更改结构或选模。正式复核前需要正视该条件限制。

计算成本同样重要：RTX5090、batch128下，S0/S1训练分别6.44/6.54分钟、推理1.49/1.57ms；E6两阶段37.44分钟、18.28ms，R3两阶段53.21分钟、28.04ms。S0/S1只需49880个名义训练参数，阶段一训练成本0；精度收益不能脱离成本讨论。

## 4. 精恢复两路径：普通网络残差承担主要增益

| 粗恢复 | 精恢复配置 | MSE | MAE |
|---|---|---:|---:|
| R3 | P0 五组输入＋网络残差＋邻点门控 | **0.123941** | **0.188432** |
| R3 | P1 五组输入，仅网络残差 | 0.123947 | 0.188491 |
| R3 | P2 粗结果/可见值/mask，仅网络残差 | 0.124568 | 0.188867 |
| R3 | P3 五组输入，仅邻点门控 | 0.146865 | 0.210880 |
| T1 | P0 完整精恢复 | **0.129252** | **0.193203** |
| T1 | P2 普通网络残差 | 0.130401 | 0.194083 |

- P0/P1：移除直接门控，R3 MSE仅增加0.005%，未显示重要额外收益。
- P1/P2：邻点信息作为输入，MSE约改善0.50%，是小幅辅助。
- P0/P3：仅门控的P3 MSE比完整增加18.50%，自由网络残差是重要路径。
- 跨骨干P0/P2：R3和T1分别有0.50%、0.88%的MSE改善，方向一致但幅度有限；未证明跨训练seed稳定或显著。

P2保留真实可见值和mask，因此不代表“没有观测信息”。当前更准确的表述是：**可见观测条件下的普通网络残差恢复承担主要精度收益；显式邻点信息提供小幅辅助，直接邻点门控尚未显示决定性增益。** 不应把直接门控包装为核心创新。

P1/P2/P3保留相同卷积/Transformer骨干，删除不用的780参数输出头；头注册参数49100，P0为49880。P2的1536个输入权重接恒零通道，不虚报为额外有效能力。P0/P1也改变可达残差范围，不把全部差值解释为邻点语义。无训练插值参照仍是0.646354/0.464819，不能混为S1精恢复后成绩。
