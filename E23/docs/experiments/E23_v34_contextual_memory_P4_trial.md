## 固定设置

A仅将query及检索配对监督对齐到训练集全局标准化尺度，与库中raw patch生成key的尺度一致。B进一步将检索输入扩展为48点：目标16点、左16点、右16点；库只保存训练窗口原可见上下文及mask，raw候选中心仍必须完整可见。全缺失patch可依据邻近观测检索，候选所有已观测上下文必须早于query patch起点。最终仍选四个候选，阈值0.7；在线库容量、EMA、快照和FIFO设置不变。

两项均从头100轮Stage1+100轮Stage2，单轮T→V→H、修复D64、原PatchTST D16。seed2021、batch128、FP32，Adam lr0.001/0.0001、weight_decay0。Stage1全局修复MSE+0.1检索损失，验证修复MSE选模；Stage2原纯预测MSE，固定验证MAE选模。原预测头35427参数，Stage2函数与预测头源码、初始化SHA均核对一致。没有新增辅助预测器、修复保留损失或冻结日程。

ETTh1 P4 96→96，块起始率0.10、块长8、允许重叠。每项锁定后测试原三组位置；每组2688窗口、1806336预测坐标。均值±总体标准差只描述缺失位置变化，训练仅一次。
