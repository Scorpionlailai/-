# E23 v19: implicit recovery at the forecast interface

Predeclared 2026-10-01, before training. Current ETTh1 P4 incumbent v12 has validation forecast MSE/MAE `0.7454477286392869` / `0.5882120694703256` and selected test `0.4256128043003904` / `0.431006140719736`. V18's stronger T attention failed the same validation gate and received no test evaluation. This trial changes **only the handoff from the v12 latent repair encoder to its existing PatchTST predictor**. It reuses the exact selected v12 Stage-1 checkpoint, H bank and retrieval key; H, V, T, shared router, repair width 64, and the original width-16 PatchTST encoder and forecast head remain as in v12. The predictor and a small input adapter start fresh for Stage 2.

The v12 interface decodes the routed repair latent into values, merges overlapping patches, hard-preserves observed values, re-patches the resulting explicit sequence, then projects those patches into predictor tokens. V19 instead feeds the routed latent `z_rec` to a zero-initialized bias-free `Linear(64,16)` adapter **at the prediction interface**. Its output is added only for damaged patches to the original PatchTST projection of the currently observed patch (hidden and invalid coordinates forced to zero) and the existing original-missingness projection. The original PatchTST encoder and forecast head then consume these tokens. The explicit sequence can still be computed for Stage-1 supervision/diagnostics, but Stage-2 predictions do not depend on the explicit decoder or recovered numerical values. Observed inputs and original masks remain available to the predictor; no future labels enter the adapter or recovery evidence.

Train one fresh 100-epoch Stage 2 from the selected v12 Stage 1 using seed 2021, batch 128, learning rate `1e-4`, and `MSE + 0.2 MAE`. Select the earliest minimum fixed-validation forecast MAE. Verify checkpoint/manifest identity, full epochs, frozen H state, and exact selected-validation replay. Promote only if validation MAE is strictly below `0.5882120694703256` **and** validation MSE is no higher than `0.7454477286392869`; otherwise retain v12 and do not run v19 on test. This isolates the prediction-interface hypothesis but remains one seed on a repeatedly used ETTh1 validation set.
