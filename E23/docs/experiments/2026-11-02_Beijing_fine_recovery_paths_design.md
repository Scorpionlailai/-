# Beijing sr020_bl8：阶段二精恢复两条修正路径

本轮集中验证精恢复内部机制，不新增候选来源或其他三专家消融。只用seed2023完成本轮四组训练；同一数据划分、自然缺失、训练mask流、固定验证和20组测试遮挡。全部粗恢复器冻结，不涉及下游预测Stage2。

## 代码审计

实际精恢复为 `r2_variants.Calibration` 包裹 `GlobalDenseRefiner`，single64、depthwise Conv7＋channel mix、一层Transformer、两个零初始化线性输出。五组输入全部在训练全局标准化坐标：

1. 粗恢复结果（detach，仅作条件输入；局部归一化粗结果另作最终残差起点）。
2. 真实可见值，其他位置为0。
3. 真实观测mask。
4. 邻点建议残差 `(guide-coarse)*support`，只在有合法邻点时生效。
5. 邻点支持度：双侧按间隔、单侧按距离做固定指数衰减，尺度16。

Guide只利用当前窗口同变量的真实可见点：双侧线性插值、单侧最近可见点，无同变量可见值时为训练标准化0。初始化和guide不能读取人工隐藏或原生缺失标签。

网络残差 `delta = 2*tanh(output(x)/2)` 在训练全局标准化坐标中限制在(-2,2)；仅原几何有效且缺失、并且窗口内有任意可见信息的位置生效。

邻点修正为 `tanh(guide_gate(x))*(guide-coarse)`。它是带符号修正，不是sigmoid凸插值；仅原几何有效且缺失、同变量有可见信息的位置生效。

两条修正相加后转回全局尺度并保护真实可见值。无观测窗口沿用原保护。自然真值有效性通过valid_for从训练监督、选模和测试坐标中排除；几何sequence validity保持R3原实现。

所有新头先调用相同seed2023的原P0工厂，然后移除不用的输出层，保留的骨干和输出初始化逐值相同。没有借用P0已训练的权重作为新训练起点。

P0/P1检验直接门控路径；P1/P2检验邻点信息作为输入；P0/P3检验自由网络残差。P2仍有真实可见值和mask，因此本轮检验的是显式邻点组织/直接修正的额外价值，不是“完全没有观测引导”与“有观测”的区别。

P0/P1也改变可达修正范围，这是删除邻点直接路径的实际后果；不能把所有差距仅称为邻点语义收益。P1/P2输出范围相同，是隔离邻点条件输入较干净的比较。

## 粗恢复和P0复用

R3固定原H_GLOBAL main/best.pt和对应检索状态，严格载入全部权重和原型库，核对原文件SHA、库hash及验证回放；不改变候选、CNN、Signature或confidence。不同臂接收同权重、同mask和窗口的冻结粗输出，测试时逐mask回放也必须与原P0粗输出一致。

T1固定commit `7e6b3e8f06d9081b989f90e6406a7b466ed262d6`发布的stage1 selected.pt，SHA256 `42b4503250affe8ab8ff95367a8d62ce2079918b1f9b5c5bec0e147e9f846dde`。沿用先前T1 bridge，不改变T1归一化或输入mask设置。

R3 P0与T1 P0复用现有原训练100轮、batch128、19000更新、同损失和验证MAE选模结果。短跑必须把重写的P0 forward与原GlobalDenseRefiner在实际训练好的P0权重上比较，输出逐值一致，再回放完整3411个验证窗口确认与保存指标一致。复用无新增训练。

## 预算与流程

新臂：100轮、batch128、19000更新；Adam .001，weight_decay0，FP32，无早停、调度或裁剪。损失为人工隐藏且原有真值位置的全96点MAE＋0.25近32点MAE。固定验证mask2021，以全96点MAE选主checkpoint；另存MSE次选，但不替换主结果。

训练mask/order seed2023，模型seed2023。每轮输入fingerprint与R3原精恢复轮次一致；粗模型及原型库每轮完整hash核验，冻结参数不得有梯度。测试mask2026101301–2026101320，只有满预算且主checkpoint锁定后才评价；不按测试结果改结构或选模。

GPU0：R3 P1→R3 P3；GPU1：R3 P2→T1 P2。优先完成R3关键对照，T1只复核事先固定的P2/P0，不扩展T1其他变体。每任务先通过独立验证短跑和精确导出，再进入100轮训练。

## 必要检查与报告

- 对每个头，保留参数的初始state_dict与P0逐值相同。
- 在同一个实际粗batch和同一训练好的P0骨干上，P0/P1/P3五组输入完全相同，P2前三组相同、后两组全零。
- 原P0和新实现P0输出逐值一致；P0修正等于P1修正＋P3修正（只允许FP32加减顺序误差）。
- epoch0输出等于粗恢复，隐藏输入变化不影响结果，真实可见值保持，batch128前向/梯度有限，P2恒零列梯度也为0。
- 短跑2轮各1batch，只使用验证，不用于结构搜索或最终性能结论。导出头绑定固定粗模型SHA，严格恢复后输出相同。
- 报告full96/recent32粗输出及精恢复MSE/MAE，20mask配对差、参数及条件不活跃输入、峰值显存、完整新增阶段耗时、同RTX5090 batch128的p50。

单训练seed只作开发证据，20mask不能冒充20个训练seed。若P2接近P0，应将主要收益归于普通网络残差/新增训练而非强包装邻点机制；若两骨干均支持P0，也仅对本协议作条件结论。所有负结果保留，本轮不根据测试增加变体。
