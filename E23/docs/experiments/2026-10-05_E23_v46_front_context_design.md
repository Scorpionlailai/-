# E23-v46：在 H/V/T 之前增加可见上下文编码

状态：实现、45项针对性测试、GPU检查通过；从头训练100＋100轮、20组测试及验证修复诊断全部完成。

## 本轮唯一结构变化

沿用 ETTh1 回溯96、预测96，起点率0.15、块长8、允许重叠；复用已有场景，20组测试窗口实际平均缺失72.9252%。训练seed502、固定验证mask seed2021；测试位置seed2026100401至2026100420。

在原Linear(32→64) patch表示上叠加一个可见上下文潜表示，再进入现有T→V→H单轮修复。各变量共享一个时间CNN，前端不混合变量。五种输入为可见的训练全局标准化值、可见mask、时间位置、左/右最近可见点距离（除96；无可见点为1）。先遮住缺失值再做计算，不读隐藏真值或未来目标。

CNN输入5→64，两个残差块，各含depthwise kernel7/31、dilation分别1/2、pointwise 64→128→64，残差比例0.1；最大时间感受野91点。按原patch16/stride8有效点均值池化成12个patch，再LayerNorm和64→64零初始化投影，形成潜表示增量。该分支只输出潜表示，不输出最终插补数值。

新增43200参数；修复器174362→217562参数。预测头仍为原PatchTST（35427参数），源码、配置和初始权重SHA保持。新增模块构造在独立RNG域内，零输出初始化使整体初始预测与原模型完全一致。

## 保留的实验配方

H原始可见patch检索、top4/阈值0.7、全缺失查询禁用，V原窗口top4选择与候选规则、T原时间带，以及原最后32点修复CNN保留。前端增强候选的上下文兼容性和消息处理，没有修改H原始检索key、V硬候选选择或候选可用条件。本轮不实现新的逐点专家选择或多轮候选刷新。

Stage1：100轮，batch128，FP32，lr1e-3，训练全局标准化隐藏MSE+0.1检索损失；按同尺度验证修复MSE选模，无辅助预测。
Stage2：100轮，batch128，FP32，原预测MSE+0.2MAE，第11轮起0.05均匀修复保留；预测器lr1e-4、修复器lr1e-5，冻结H检索key和库。原legacy padding/RNG配方，按固定验证MAE选预测权重。

相对该场景原v41-slow，预先锁定接受门槛：验证MSE低于0.7947543159363761，验证MAE不高于0.6070569604973134。测试在权重与验证判断锁定后执行，同一20组测试mask；测试不参与选模。T1和v41结果复用已有完整记录，不重新训练。
