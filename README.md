# PRISM — English manuscript

Overleaf-ready English source. Main document: `main.tex`.

## Import into Overleaf
1. Choose **New Project → Upload Project**.
2. Upload `prism_english_overleaf.zip` from the GitHub release.
3. Set **Main document** to `main.tex` and **Compiler** to **XeLaTeX**.
4. Recompile. All figures, equations, tables and bibliography files are included.

The root source tree can also be imported through Overleaf’s GitHub integration.
This is a working draft; sections following Main Results are intentionally deferred.
