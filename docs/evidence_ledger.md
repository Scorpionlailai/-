# 数字、模型和写作口径

## 固定模型

原完整R3/H_GLOBAL，保留后端可见邻点、q+r联合残差头、学习式Confidence。不是CURRENT_MODEL指向的另一路去邻点开发版。Signature交互直接借鉴T1的Channel--Head几何，正文已引用。V选择为window_context_topk_v1，而非全局固定来源；H查询和键监督为train-global。精恢复输入为粗值、原可见值、mask、支撑加权参考差、参考支撑；内部一层4头Transformer，主干逐点读取8头。

## 数据来源

`data/source_manifest.json`保存原来源路径、SHA256及用途。`tools/generate_tables.py`先检查所有快照哈希，再生成表格与正文百分比宏。

- 正式结果：R3四数据集正式归档＋Weather/PAMAP2另一台服务器正式归档，共六数据集×四场景×三训练seed×20test masks。仅报告本模型实测值，未填入未审核的其他模型成绩。
- 机制分析：2026-11-06补齐队列，ETTh1 sr010_bl16和PAMAP2 sr015_bl8。R3/E6为三训练seed；PAMAP2其余组件为seed2023，表注保持区分。
- PAMAP2正式评价mask2026101401–2026101420；机制分析mask2026101801–2026101820，训练模型也是独立队列。不能把0.326661和0.324572混称同一条正式结果。
- Beijing公共精恢复：seed2023，同20mask，T1/E6/R3固定骨干。不能把单seed结果与正式3seed均值混算。
- 置信区间/显著性检验未进行；样本SD来自训练种子，不是20组遮挡。

## 本版展示

六数据集正式结果、完整候选容量匹配对照、E0/E1/E2/E3/E4/E5/E6/E8、粗精阶段、同精恢复骨干比较、效率与读取头数敏感性。机制数值和负向变化保留在原快照；正文围绕主结论组织，不写代码排查和运行细节。

外部全部基线总表需要从已有记录另行整理和审核。旧v125成绩不代替当前R3。当前稿件未使用“全部六数据集SOTA”“每个来源不可替代”“显著优于”等未验证结论。
