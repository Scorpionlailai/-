# Weather E24-v79 与 SAITS 修复差距诊断（2026-10-08）

结论：存在数据预处理问题，但尚不能将模型差距归因于数据集。直接确认的是训练/选模目标不同，以及多个变量的典型误差明显不同；因果贡献需消融验证。

## 正式20组测试掩码

两边数据manifest SHA一致，20组seed、mask SHA及全96/末32点隐藏坐标数逐一一致。E24评估将窗口归一化误差乘query_std；SAITS输出和目标均为训练集标准化坐标。因此统计口径一致，均只统计人工隐藏坐标，等权平均各mask。

| 指标 | 我方相对SAITS高 | 我方更优的mask数 |
| --- | ---: | ---: |
| 全96点MSE | 1.01% | 10/20 |
| 全96点MAE | 41.92% | 0/20 |
| 末32点MSE | 1.03% | 9/20 |
| 末32点MAE | 54.05% | 0/20 |

MSE均值差很小，且逐mask有胜负，不能宣称MSE全面落后。MAE差距则在全部20组mask上同向；这些mask共享时间序列且训练种子只有一个，不能充当独立训练重复。

## 训练/选模差异

E24 Stage1 = 训练集标准化坐标的隐藏点MSE + 0.1检索损失 + 末32点均值结构损失；按validation MSE选第96轮。SAITS Stage1 = 观察点重构MAE + 隐藏点修复MAE；按validation MAE选第65轮。Stage2两边修复器冻结，预测头训练不会修正修复差距。

我方第96轮validation MAE 0.119913；整段100轮历史中MAE最低为第99轮0.115696，仍明显高于SAITS的0.078939。仅更换选模指标不太可能消除当前差距；第99轮未进行新测试。

20-mask结果按隐藏坐标数量反推，前64点MAE均值我方约0.076599、SAITS约0.056441；末32点为0.088876、0.057692。末32点明显放大差距。近期均值投影/点细化/结构损失是值得分别消融的对象，目前尚不能指定某一模块为原因。

## 数据问题

start_rate=0.15是每个时间位置缺失块起始概率，不是最终缺失率。block_len=8且允许重叠；理论上内部位置缺失概率1-(1-0.15)^8约72.75%，20组实际timeline平均72.77%。第一组mask的连续缺失段中位数14点、99分位62点、最长107点。该实验属于高缺失、可合并成长缺口的场景。

CSV读取仅检查数值有限，没有过滤-9999。训练集风速wv有1个-9999，标准差52.0994，排除该值后为1.66719（31.25倍）；OT有50个-9999，标准差383.957，排除后18.1821（21.12倍）；max.PAR有30个-9999，标准差放大1.126倍。这些值全部位于训练段。此处“排除后”仅为统计诊断，没有改变任何训练数据、标准化器或模型。

标准化被异常值影响会改变变量的损失权重和训练目标。这些问题两边共有，不能据此推断清洗后排名将反转。

## 第一组固定测试mask的只读逐变量诊断

seed=2026100801，加载原选定Stage1权重及我方记忆库，只进行eval/no_grad前向，无训练、无优化器更新。逐变量结果存于同目录result.json；单mask复现正式指标：我方MSE0.05105055、MAE0.07939054；SAITS MSE0.05278399、MAE0.05645144。

绝对误差中位数我方0.0268581、SAITS0.0102248。99.9分位我方2.87683、SAITS3.39674，显示本mask中我方典型误差较大、极端误差较小。风向wd和降雨时长raining(s)合计约70.75%的我方MSE、82.29%的SAITS MSE，MSE主要受这两列影响。

温度T：MSE我方0.005241、SAITS0.000802；MAE 0.042559、0.016801。相对湿度rh：MSE0.033084、0.005639；MAE0.101496、0.051485。多数温湿度/辐射列存在相似差距，不能仅用两个总体MSE接近来认定修复质量相当。单mask逐变量结论不能替代20-mask统计。

## 建议验证顺序

1. 建立独立清洗协议：确认-9999的原始语义，作为原生无效/缺失值处理，仅有效训练值拟合scaler；评估人工隐藏且拥有有效真值的坐标。保留原封存结果，两边重新训练/评估同一新协议。
2. 固定数据与架构，单独比较MSE、MAE、MSE+MAE目标及相同选模规则；随后再比较是否加入观察点重构监督。
3. 单独移除末32点均值结构损失、近期均值投影及点细化，按validation判定，正式test仅用于预先固定方案的最终评价。
4. 扩展逐变量和误差分位数报告，并增加训练种子，区分普遍误差与少量极端误差。
