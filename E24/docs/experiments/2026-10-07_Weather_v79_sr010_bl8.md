# E24：Weather 上从头复现 v79，0.10 / 8

## 授权与边界

用户授权先在 Weather 跑一版起点率 0.10、块长 8。本轮仅训练 E24-v79，不恢复已暂停的 E23 迭代队列，也不自动启动 T1 或其他基线。训练结束后测试预先封存的 20 组缺失位置。

协议 ID：`E24-weather-v79-sr010-bl8-seq96-pred96-all-eval-v1`。架构父版为 E23-v79，模型 seed=2023；这一轮不是多训练种子实验。

## 数据身份与切分

- 原始文件：`/home/xyw/paper/data/raw/weather.csv`，52696 行、21 个变量；保持原始列与行顺序。
- 名义采样间隔 10 分钟。原文件在行19043之后有重复时间戳，在行21513之后有6000秒间隔；不删除、插值或重新采样。这些异常在数据 manifest 中保存。
- 按时间切分：训练 `[0,36887)`；验证 `[36887,42157)`；测试 `[42157,52696)`，与原 E22 Weather 切分一致。
- 历史窗口96、预测长度96。标准化仅拟合训练行，未来目标不缺失、不作为修复器输入。验证/测试的输入可以读取边界前96点，预测目标严格留在所属 split 中。
- 可用窗口：训练36696、验证5175、测试10444。训练每轮使用36608窗口（286×128），末尾88窗口因 shuffle/drop_last 在不同轮次变化。
- Weather 验证和测试保留全部有效窗口，包括末尾不足128的 batch。ETTh1 原有截断逻辑保持不变；所有后续 Weather 基线须按此协议保留全部窗口。

## 缺失与随机性

- 参数为块起点率0.10、块长8，变量独立采样、起点不重复、块允许重叠。这不是“实际缺失10%”。
- 训练每轮重新采样：同一生成器，以 seed2023、epoch、窗口标识共同确定局部96点 mask。
- 固定验证 mask seed=2021，一套位置决定 checkpoint。
- 测试20组 seed：`2026100801..2026100820`；它们是整数种子标识，不代表实际生成日期。均在2026-10-07正式训练前生成并封存。
- 一组 mask 覆盖整个测试时间轴，再切成10444个窗口；并非20条样本，也不是20次训练。后续基线直接复用同一文件和SHA。
- 数据、列顺序、训练统计、切分、mask配置/文件/seed/SHA均写入 `shared_protocol_v1/dataset_manifest.json` 和旁边的 `.sha256`。

## 结构与训练配方

沿用 v79 全部活动模块：D64；CNN窗口上下文；两层变量 signature 上下文及学习位置；单轮 T→V→H；当前窗口选四个变量来源；H top-k4；八头候选读取；逐点路由；重叠置信融合；最近32点修复；全局可见信息驱动的近期均值投影。

必要维度适配仅包括21变量身份编码、变量/时间位置、跨变量全局统计输入。修复器参数从424238增至519214。预测头源文件不变；仍是 D16、4 heads、FF128、3层、P16/S8、dropout/fc_dropout0.3。预测头参数35427，其初始化SHA与父v79完全一致。

| 阶段 | 固定设置 |
|---|---|
| Stage1 | 从头训练100轮；batch128；Adam lr0.001、WD0、FP32、固定学习率 |
| Stage1 损失 | 训练标准化尺度上的缺失MSE + 0.1 retrieval；recent_mean_v2 的近期level权重1、trend权重0；specialist exposure0.2 |
| Stage1 选模 | 固定验证全96点缺失坐标 global MSE 最小；不使用预测/测试结果 |
| Stage2 | 从头训练原预测头100轮；batch128；Adam lr0.0001、WD0、FP32；预测损失纯MSE |
| Stage2 冻结 | 整个修复器参数、缓冲、Dropout/BN模式、历史库、检索与EMA均冻结，只更新预测头 |
| Stage2 主选 | 固定验证MAE最小 |
| Stage2 次选 | 同一轨迹另存验证MSE最小，作为次要结果，不替换主表 |
| 更新预算 | 每阶段28600个optimizer steps，不能用ETTh1的6600步填写 |

训练前检查：batch128的21变量前向/反向有限值；可见坐标原值保持；隐藏真值和未来目标不进入输入；optimizer仅含预测头；一次预测头更新后修复状态不变；5175/10444个验证/测试窗口完整保留；ETTh1父权重的完整验证预测复现。见 `preflight_acceptance.json`。预检产生的一次临时预测头更新未保存或用于正式训练。
