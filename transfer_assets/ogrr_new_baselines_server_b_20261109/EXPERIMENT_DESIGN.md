# New imputation baselines + OGRR, 2026-11-09

Authorized scope: SAITS, ModernTCN and PyPOTS TimeMixer++ on ETTh1, Weather, Exchange-Rate, BeijingAirQuality, PAMAP2 and PhysioNet2012. Four scenes: sr015_bl8, sr010_bl8, sr020_bl8, sr010_bl16. 72 original-model runs and 72 OGRR runs; no forecasting. CSDI workers stopped, prior records and checkpoints preserved.

## Data and evaluation
Reuse original shared data, train-only statistics, native-valid masks, per-record/station/patient boundaries and all 21 original validation/test masks. Validate arrays against original banks. Every selected model is evaluated on the same 20 test mask seeds. Metrics cover only originally observed, artificially hidden entries. All 96 history points; no future labels are loaded. Training masks remain dynamic, fixed generator seed2023 for shared inputs, independent of author model seed. Tests run only after both stages select their checkpoints.

Batch32 is an explicit memory adaptation versus paper512; no added normalization. Same profile across all six datasets; no test-guided tuning.

## Frozen OGRR
Use archived PRISM single64 refiner unchanged; seed2023, FP32, batch128, Adam .001, no weight decay, full100 epochs. Actual archived objective is hidden native-valid full96 MAE + .25 last32 MAE; select full96 validation MAE. The selected complete initializer is strictly frozen, eval mode, gradient-free, with parameter/buffer digest checked every epoch. Validation coarse predictions are cached; training masks are not fixed or cached. Coarse and head export replay, hidden-input invariance, observed-value preservation and finite gradients are checked before full runs.
